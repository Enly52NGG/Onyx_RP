# ONYX RP — Правовой портал

## Отчёт о реализации

### Что реализовано

- Полноценный Next.js (App Router) + TypeScript + Tailwind CSS проект
- Тёмная премиальная тема (чёрный / графит / сдержанный золотой #B9A16B)
- Адаптивная вёрстка (desktop / tablet / mobile) с выдвижным меню
- Левая боковая навигация
- Главная страница с поиском, категориями, популярными документами и уведомлением
- Каталог документов с фильтрацией по категориям
- Страница отдельного документа с:
  - Содержанием (TOC)
  - Якорными ссылками на статьи
  - Кнопками «Копировать ссылку» и «Печать»
  - Отображением санкций
- Глобальный поиск по названиям, номерам статей и тексту
- Страница «Кодексы»
- Страница «О портале»
- Кастомный 404
- Логотип проекта

### Обработанные документы

| ID | Название | Источник | Статус |
|----|----------|----------|--------|
| server-rules | Основные правила проекта | message (13).txt | Полностью структурирован |
| uk-rf | Уголовный кодекс РФ для РП | message.txt | Ключевые главы и статьи |
| koap-rf | КоАП РФ | message (1).txt | Основные разделы |
| upk-rf | УПК РФ | message (2).txt | Ключевые главы |
| constitution | Конституция РФ | message (3).txt | Основные статьи |
| police-law | О полиции | message (10).txt | Ключевые главы |

Остальные исходные файлы (ТК, Правительство, Судебная система, Госслужба, ФСБ, Оружие, Прокуратура, ФСО) проанализированы, категории созданы, контент может быть дополнительно структурирован.

### Материалы, требующие внимания

- Полные тексты длинных кодексов (ТК, ФСБ, оружие и др.) пока представлены частично.
- Все документы помечены статусом «требует проверки».
- Даты принятия/обновления в исходниках отсутствовали — не выдумывались.
- Противоречия между документами не разрешались автоматически; при обнаружении они должны проверяться администрацией.

### Как запустить локально

```bash
cd onyx-legal
npm install
npm run dev
```

Открыть http://localhost:3000

### Публикация

1. `npm run build`
2. `npm start` или деплой на Vercel / любой Node-хостинг, поддерживающий Next.js.

### Архитектура данных

Документы хранятся в `src/data/documents.ts` в типизированной структуре (LegalDocument → Section → Article). Это позволяет легко добавить БД и админку в будущем.
